# Assessment Requirements

## Task 1: E-commerce ERD

Design an entity relationship diagram for an e-commerce system containing customers, categories, products, orders, and related tables.

Implemented in `01-erd`.

## Task 2: PHP/MySQL To-do List

Create a to-do task list containing CRUD actions using PHP and MySQL. A PHP framework is optional.

Implemented in `02-todo-app`.

## Task 3: Reversi Game

Complete the provided Reversi starter file with as many requested functions as possible:

1. Check available slots
2. Flip opponent pieces
3. Victory condition
4. Draw condition
5. Show legal moves
6. Display score
7. Undo a move
8. Suggest a move
9. Player versus computer

Implemented in `03-reversi/reversi-game.html`.
