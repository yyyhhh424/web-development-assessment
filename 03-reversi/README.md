# Reversi Game

This file completes the quiz requirements from the supplied starter HTML.

## Implemented requirements

1. Checks whether a selected square is empty and legal.
2. Flips surrounded opponent pieces in all eight directions.
3. Declares the player with the higher score as the winner.
4. Declares a draw when both scores are equal.
5. Shows all legal moves with light markers.
6. Displays live Black and White scores.
7. Supports undo/“regret piece”.
8. Provides a suggested move using a simple corner-first strategy.
9. Supports Player vs Computer mode.

Additional behavior:

- Automatically skips a player with no legal moves.
- Detects the end of the game when neither player can move or the board is full.
- Responsive layout for desktop and mobile.

## Run

Open `reversi-game.html` in a browser. An internet connection is required for the Vue 2 CDN script.
